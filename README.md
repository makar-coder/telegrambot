# Бизнес-бот для родительского контроля

Перехватывает все сообщения в аккаунте и пересылает админу.

## Как развернуть на Railway

1. Создай новый проект на Railway.
2. Подключи GitHub-репозиторий с этими файлами.
3. В переменные среды добавь:
   - `BOT_TOKEN`
   - `ADMIN_ID`
4. Railway сам определит Python и запустит через `Procfile`.
5. После деплоя перейди в Telegram → Настройки → Бизнес-боты → подключи своего бота.

## Проверка

Если бот работает — в логах Railway увидишь `🚀 Бот запущен...`.
